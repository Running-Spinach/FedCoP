## 1. 一句话概括

**FedCoP = 在联邦多标签医学影像里,各医院的"疾病共现规律"(哪些病常一起得)没有任何一家医院能完整看到,只有联邦聚合才能恢复。FedCoP 把这个全局共现矩阵 R̂ 联邦地估计出来,既用来约束各类原型的相互几何(训练侧 L_co),又用来在推理时跨类传播证据(mean-field 解码),从而打破旧方法"14 种病相互独立"的错误假设。**

理解了"共现结构是联邦特有、必须聚合才能恢复"这一点,所有公式都围绕它展开。

---

## 2. 背景:原型联邦学习卡在哪

### 2.1 原型联邦学习(FedProto)

FedProto 不共享模型权重,而是共享**原型**(每类特征的均值向量):客户端上传各类原型,服务器平均得到全局原型,客户端再把自己的特征拉向全局原型。优点:通信小、隐私好、与模型架构无关。

后续工作(FedGMKD/FedBCS/FedSeProto/旧 D²-FL)改进了原型的**表示**(GMM、解耦、分布头)和**聚合**(质量加权、贝叶斯),但都保留了一个错误假设 ↓

### 2.2 致命假设:14 种病相互独立

所有现有原型方法都把 14 类原型当作**互相独立的集合**:
- **存储/对齐独立**:原型存成 `{p_c}`,对齐损失逐类独立算。一张同时含"积液+浸润"的图,产生两个互不相关的对齐梯度。
- **解码独立**:推理时 `p(y_c=1|x) = σ(-d_c/T)` 逐类独立 sigmoid。

这等价于假设"给定特征,14 个标签条件独立"。但胸片标签强相关(共病是常态),所以这个假设错得离谱,解码器也就不是最优的(见命题1)。

---

## 3. 核心洞察:共现结构是"联邦特有"的

关键:**共现结构是非局部的**。Non-IID 划分下每个客户端只见 `ways ≪ C` 类(如 3/14),它自己的共现矩阵 M_k 对没见过的类整行整列是 0,**没有任何一家医院能单独看到全局共现**。只有联邦聚合各客户端的标签统计量,才能恢复完整的 C×C 共现结构。

这让"共现建模"不只是把集中式多标签技巧搬进 FL,而是一个**结构上必须联邦**的量——FedCoP 的核心论点。

## 4. FedCoP 三大支柱全景

```
                ┌─────────────────────────────────────┐
客户端 k ───────▶│ 1. 分布原型 (μ_c, σ²_c)  +  L_proto  │── 上传 (μ_c,σ²_c) ──┐
                │    L_co(用全局 R̂ 约束原型几何)        │                     │
                │    上传标签统计 (m_k, M_k, n_k) ────────┼─→ 服务器聚合 R̂     │
                └─────────────────────────────────────┘                     │
                                                                            ▼
服务器: 贝叶斯融合原型 + 计数聚合共现 → R̂, π  ──(EMA)──▶ 下发原型 + R̂
                                                                            │
推理: 马氏距离 → 独立 logit s → mean-field(R̂) 解码 → 预测 ◀──────────────────┘
```

---

## 5. 支柱一:分布原型 + 贝叶斯融合

每类原型是对角高斯 `N(μ_c, diag(σ²_c))`,由 `ProbabilisticProtoHead` 从 fc1 特征产出。**故意用对角**:客户端每类样本少,对角方差估计稳、通信省、和贝叶斯融合天然兼容。跨类结构不放进每类协方差(那要估 D×D,样本不够),而是交给共享的 R̂。

**贝叶斯融合**(精度加权):
```
μ_c^g = Σ_k (μ_c^k / σ²_c^k) / Σ_k (1/σ²_c^k)
σ²_c^g = 1 / Σ_k (1/σ²_c^k)
```
方差小(更可靠)的客户端权重大。原型和 R̂ 都跨轮 EMA 平滑。

---

## 6. 支柱二:联邦共现结构 R̂

**客户端统计**(纯整数,无特征,隐私安全):
```
m_k = Y_kᵀ 1        ∈ R^C        每类边际计数
M_k = Y_kᵀ Y_k      ∈ R^{C×C}    共现计数(对角线 = m_k)
n_k = |Y_k|                       样本总数
```

**服务器计数聚合** → 边际/联合概率 → **phi 相关**(二值变量的 Pearson 相关,去除边际频率影响):
```
p_c = m_c / N,   p_cd = M_cd / N
R_cd = (p_cd - p_c·p_d) / sqrt(p_c(1-p_c)·p_d(1-p_d))   ∈ [-1, 1]
```
**收缩** `R̂ = (1-η)R + η I` 保证正定 + 小样本稳定;再跨轮 EMA。同时得到全局边际先验 `π = p`。

---

## 7. 支柱三-A:训练侧共现结构损失 L_co

把本 batch 出现类的均值原型归一化后堆叠 `P̂ ∈ R^{C'×D}`,余弦 Gram `G = P̂ P̂ᵀ`,对齐到 R̂ 对应子块:
```
L_co = ‖G - R̂_S‖_F²
```
含义:共现的病 → 原型方向相近;互斥的病 → 远离。这就把原本"互相无关的原型集合"耦合起来,用**标签统计驱动**的 R̂ 约束,替代了旧 D²-FL 里启发式的对比损失和对抗损失(都分析为冗余)。

---

## 8. 支柱三-B:推理侧 mean-field 结构化解码

每类马氏能量 `e_c = ½ Σ_d (x_d-μ_cd)²/σ²_cd`,独立 logit `s_c = -e_c/T`。不做独立 sigmoid,而是把联合标签分布建模为带成对耦合 R̂ 的 Bernoulli,跑**变分 mean-field**:
```
q_c ← σ( s_c + β · Σ_{d≠c} R̂_cd · (q_d - π_d) )    迭代 K 步
```
直觉:与"证据超过先验的共现类"耦合 → 抬高本类概率(共病诊断)。R̂=I 时耦合项为 0,退化为独立 sigmoid(消融基线)。复杂度 O(B·C²),C=14 在 4090 上可忽略。

## 9. 完整损失函数与砍掉的 trick

**4 项损失(刻意精简):**
```
L = L_CE + λ_eff·L_proto + λ_co·L_co + λ_ent·L_ent
```
- L_CE:多标签分类(BCE)。
- L_proto:本地→全局对角高斯 KL,逐正标签;λ_eff 含 warmup。
- L_co:共现结构对齐(§7)。
- L_ent:`-mean(log σ²)`,防方差坍缩回点原型(小权重 guardrail)。

**砍掉的 trick 及原因:**

| 组件 | 处理 | 原因 |
|---|---|---|
| 每类温度 | 砍 | 训练了但推理从没用(死代码) |
| 对抗域不变(GRL) | 砍 | 与解耦独立性目标重复;GRL 不稳 |
| InfoNCE 对比 | 砍 | 与 L_proto+L_CE 重叠;被 L_co 替代 |
| 校准损失 L_cal | 砍 | 把 (B,D) logvar 坍缩成标量;治标不治本 |
| 语义-风格解耦 | 砍 | 另一条故事线,稀释共现主线;最重的部件 |
| 熵正则 L_ent | 留 | 真正的防坍缩 guardrail |
| 贝叶斯融合/EMA/warmup | 留 | 自然稳定器(不当创新吹) |

## 10. 理论:两条命题

**命题1(解码次优性)**:独立逐类 sigmoid 仅在"标签条件独立于特征"时 Bayes 最优;残差标签相关下,其 regret ≥ c·‖Σ_y − I‖_F²。mean-field 解码是耦合 Bernoulli 模型 mean-field ELBO 的不动点,regret 被降为变分间隙(当 R̂→Σ_y 时消失)。故 R̂≠I 且估计良好时,结构化解码严格优于独立 sigmoid。

**命题2(联邦共现可恢复性)**:
(a) 无偏:计数聚合估计器 R̂(非均匀参与下经重要性重加权)满足 E[R̂]=R⋆。
(b) 收敛:由 matrix-Bernstein,`P[‖R̂−R⋆‖_∞ > ε] ≤ 2C·exp(−ε²·K·n_min/(c'·log C))`,速率 Õ(√(log C/(K·n_min)))。
(c) 单客户端不可恢复:每客户端只见 ways<C 类,其 M_k 对未见类对全为 0,**任何单客户端都无法识别**未见类对的共现。全局 C×C 结构只能由类支持联合覆盖全部 C 类的客户端联邦聚合恢复——这正是共现结构"必须联邦"的形式化。

## 11. 消融实验设计

| 变体 | R̂ | L_co | 解码器 | 隔离的贡献 |
|---|---|---|---|---|
| FedCoP(完整) | 联邦 | 开 | mean-field | — |
| `--no_cooccurrence` | I | 关 | 独立 | 共现结构总贡献 |
| `--local_cooc_only` | 各客户端本地 | 开 | mean-field(本地) | 联邦聚合的必要性(命题2c) |
| `--no_lco` | 联邦 | 关 | mean-field | 训练侧 vs 推理侧结构 |

预期:完整 > no_cooccurrence(结构有用);完整 > local_cooc_only(联邦聚合必要,尤其罕见/共现类);no_lco 介于两者间(推理侧结构单独也有部分增益)。

## 12. 训练流程伪代码

```
每轮 t:
  服务器采样客户端 S_t;下发 {μ_c^g, σ²_c^g} 和 R̂, π
  每客户端 k ∈ S_t:
      本地 SGD: L = L_CE + λ_eff·L_proto + λ_co·L_co + λ_ent·L_ent   (用 R̂)
      上传每见类 (μ_c^k, σ²_c^k) 和 (m_k, M_k, n_k)
  服务器:
      μ_c^g, σ²_c^g ← 贝叶斯融合 → EMA
      R̂, π ← 共现计数聚合 → EMA
推理:
  s_c = -½·马氏(x, μ_c^g, σ²_c^g)/T
  q ← mean_field(s, R̂, π, β, K)
  ŷ_c = 1[q_c > 0.5]
```

## 14. 常见问题 FAQ

**Q1: 为什么用对角高斯而不是全协方差?**
每客户端每类样本少(~几十),估 D×D 全协方差会奇异;对角稳定、通信省,跨类结构交给 R̂(C×C=196,小)而非每类 D×D。

**Q2: L_co 和被砍的对比损失有何不同?**
对比损失用启发式 Jaccard 阈值且只看同类聚集;L_co 直接用联邦估计的 R̂ 约束原型布局,同时建模"共现拉近"和"互斥推远",动机干净、有标签统计依据。

**Q3: mean-field 解码会不会不稳?**
对角线置零避免自耦合;β 控制强度;R̂=I 时退化为独立 sigmoid。通常 1~3 步即收敛。

**Q4: 共现统计会泄露隐私吗?**
(m_k, M_k, n_k) 是标签计数,不含特征/图像,且经收缩+EMA 平滑,远比原型本身安全。

**Q5: 为什么联邦聚合共现是必要的(不能用本地共现)?**
Non-IID 下每客户端只见 ~3/14 类,本地 M_k 对未见类对全为 0,无法恢复全局共现(命题2c)。`--local_cooc_only` 消融正是用来验证这点。
